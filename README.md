# 🎨 Estudo de Tipografia e Cores - Itaú (Figma)

Este repositório contém a **Atividade 3**, um estudo prático de **UI/UX Design & Style Guide** focado na estruturação de **Tipografia** e **Paleta de Cores** inspiradas na identidade do **Itaú**, desenvolvido utilizando a ferramenta **Figma**.



# 📌 Sobre o Projeto

O objetivo desta atividade é construir um guia visual (Style Guide / Design Tokens) estabelecendo padronização de cores, escala tipográfica proporcional e validação de acessibilidade e contraste visual para componentes de interface.

* **Arquivo de Origem:** [`Atividade3_Itau.pdf`](./Atividade3_Itau.pdf)
* **Ferramenta:** [Figma](https://www.figma.com/)
* **Autora:** [Caline Myrella](https://github.com/CalineMyrella)

# 🔤 Tipografia e Escala (Font Scale)

 **Fonte Utilizada:** `Poppins`

A escala tipográfica foi definida para garantir hierarquia clara entre os elementos da interface:

| Nível / Estilo | Tamanho (px) | Descrição / Uso Recomendado |
| :--- | :---: | :--- |
| **H1** | `40px` | Títulos de grande impacto / Hero Headers |
| **H2** | `34px` | Títulos principais de seções |
| **H3** | `28px` | Títulos de subseções ou modais |
| **H4** | `24px` | Títulos de cards e destaques |
| **H5** | `18px` | Subtítulos e pequenos agrupamentos |
| **Parágrafo** | `16px` | Corpo de texto padrão da aplicação |
| **Small** | `14px` | Legendas, badges, rótulos e textos auxiliares |



# 👁️ Contraste e Acessibilidade

O projeto incluiu testes de aplicação da tipografia sobre fundos de diferentes tonalidades da paleta para testar a **legibilidade** e o **contraste** (em conformidade com diretrizes de acessibilidade WCAG).
