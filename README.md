# 🎨 Estudo de Tipografia e Cores - Itaú (Figma)

Este repositório contém a **Atividade 3**, um estudo prático de **UI/UX Design & Style Guide** focado na estruturação de **Tipografia** e **Paleta de Cores** inspiradas na identidade visual do **Itaú**, desenvolvido utilizando a ferramenta **Figma**.



# 📌 Sobre o Projeto

O objetivo desta atividade é construir um guia visual (Style Guide / Design Tokens) estabelecendo padronização de cores, escala tipográfica proporcional e validação de acessibilidade e contraste visual para componentes de interface.

* **Arquivo de Origem:** `Atividade3_Itau.pdf`
* **Ferramenta:** [Figma](https://www.figma.com/)
* **Autora:** [Caline Myrella](https://github.com/CalineMyrella)

# 🔤 Tipografia e Escala (Font Scale)

 **Fonte Utilizada:** `Poppins`

Escala tipográfica definida para a hierarquia do projeto:

| Nível / Estilo | Tamanho (px) | Aplicação |
| :--- | :---: | :--- |
| **H1** | `40px` | Títulos principais de grande impacto |
| **H2** | `34px` | Títulos de seções |
| **H3** | `28px` | Títulos de subseções/modais |
| **H4** | `24px` | Títulos de cards e destaques |
| **H5** | `18px` | Subtítulos e pequenos blocos |
| **Parágrafo** | `16px` | Texto corrido / corpo da aplicação |
| **Small** | `14px` | Legendas, rótulos e textos auxiliares |



# 👁️ Contraste e Acessibilidade

O estudo contou com validação de contraste e aplicação dos textos sobre fundos com variações da paleta de cores para garantir boa leitura e acessibilidade visual.
